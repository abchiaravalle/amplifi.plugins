We just open-sourced a WordPress plugin that lets you share password-protected pages without sharing the password.

It's called amplifi.magic.

Here's the problem:

WordPress password protection works great — until you need to share a page with a client, stakeholder, or team member.

You email them the password.
Now that password is in their inbox, their Slack, their text messages.
You have no idea who's actually using it.
And revoking access means changing the password for everyone.

amplifi.magic replaces passwords with one-click magic links.

How it works:
1. Password-protect a page in WordPress (the normal way)
2. Generate a named token for each person or group
3. Share the magic link
4. They click it and see the content instantly — no password prompt

What you get:
- Named tokens ("Client: Acme Corp", "Review: Design Team")
- Full usage logs with IP, geolocation, and timestamps
- One-click revocation per token
- No WordPress accounts required for recipients

Real use cases:
- Client deliverables and review pages
- Gated content with per-channel tracking
- Internal docs without managing user accounts
- Portfolio pieces shared with prospective clients

Every access is logged.
Every token is revocable.
Every link is independently trackable.

It's free, MIT licensed, and part of the amplifi.plugins suite.
