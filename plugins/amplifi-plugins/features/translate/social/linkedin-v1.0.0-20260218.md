We just open-sourced a WordPress plugin that translates your entire site with AI for less than $2.

It's called amplifi.translate.

Here's the problem it solves:

Most translation plugins charge $15-50/month and lock you into their platform.
Manual translation costs thousands and takes weeks.
We wanted something that takes minutes and costs almost nothing.

So we built it.

How it works:
1. Install the plugin
2. Add your OpenAI API key
3. Pick your languages (33 available)
4. Your site is now live at /es/, /fr/, /zh/, etc.

The first visitor to a translated URL triggers an AI translation.
After that, it's cached and served instantly.
Update your content? Cache auto-clears and re-translates on the next visit.

The numbers:
- One page translation costs ~$0.002 with GPT-4o Mini
- A 100-page site in 5 languages = roughly $1-2 total
- Cached translations are free forever

What's included:
- Full-page translation (nav, footer, meta tags — everything)
- Language switcher as a WordPress menu item or shortcode
- Multilingual sitemap with hreflang for SEO
- Browser language detection
- API usage tracking with cost breakdowns
- Works with any OpenAI model

It's MIT licensed, fully open source, and the first plugin in the amplifi.plugins suite.

More tools coming soon.
