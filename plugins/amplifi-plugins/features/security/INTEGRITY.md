# Release integrity manifest

This file is regenerated by the monorepo release script (`scripts/release.sh`
at the repo root) on every release. The runtime self-integrity scanner
(`Self_Integrity::verify()`) computes the same hashes on the live filesystem
and compares.

If you're reading this in a development checkout, the file is a placeholder
and the plugin records its own baseline at activation time instead.

```
# version: dev
# generated: pending — produced at release time by scripts/release.sh
```
